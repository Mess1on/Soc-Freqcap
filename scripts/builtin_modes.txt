# Soc智能限频 · 内置"满血"清单（相机类）
#
# 装机时只给**本机已安装**的包追加 `pkg=full  #builtin`，写进
# /data/adb/soc_freqcap/app_modes.conf。用户改过值、或自己删掉的行不会被覆盖/塞回：
# 升级只补"上一版清单里没有、这一版新增"的包（基准存在
# /data/adb/soc_freqcap/builtin_modes.base.txt）。
#
# 为什么相机要满血：取景、快门、连拍、4K 录像都吃 CPU/GPU 的瞬时响应，
# 这些应用在前台时本来就不在"日常待机节流"的目标里。
#
# 一行一个包名=full。这里只写各家相机的包名（不同 ROM 叫法不同），
# 没装的条目不会产生任何效果，也不会出现在页面列表里。
