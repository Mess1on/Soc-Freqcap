# Soc智能限频 · 内置「深睡永久豁免」清单
#
# 深睡会强制进 Doze。下面这些应用被一起压住会出现"锁屏收不到消息 / 音乐被掐 /
# 步数不动 / 闹钟不响"这类问题，所以装机时给**本机已安装**的包写入
# `white=包名`（等同系统电量设置里的「无限制」）。
#
# 只写 dsleep.conf，不影响分应用档位；不想要就在睡眠页删掉，
# 升级不会塞回来（基准 builtin_white.base.txt 只补"新版清单新增"的包）。
#
# 一行一个包名；# 后面是给人看的名字，安装脚本不读，页面用它显示中文名。
