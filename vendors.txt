# Soc智能限频 · 发行商词典（只用来找候选，不参与前台匹配）
#
# 这个文件不会让任何应用自动变成游戏：前台匹配只认 games.txt 里的整串包名。
# 它唯一的作用是，在 WebUI「游戏」页多列一栏
# "这台机上装了、包名里带着这些发行商标记、但还没进名单" 的候选，
# 你点一下才真的加进名单。名单覆盖不到的新游戏可以随时手动添加。
#
# 语法（一行一条，# 开头是注释）
#   +词   命中。不带点的词 = 包名按点切开后**某一段正好等于它**（不分大小写）；
#         带点的词 = 包名以它开头（如 +com.tencent.tmgp）。
#   -词   排除，判据和 + 完全一样。命中 + 之后再过一遍 -，被 - 打中的整个作废。
#   行首不带 +/- 的按 + 处理。
#
# 判据只收包名中游戏专用的那一段（如 +com.tencent.tmgp）：
#   通用公司名（tencent / netease / bilibili 等整站段）不作命中项，
#   同一公司的社区、音乐、工具类一律走排除表。
#   漏掉的候选可以在名单页直接输入包名添加。
